Horus v1.9 — Test Suite

OCTO connectivity — automatic selling. Status: Beta · Date: 2026-07-11

⚡ What's new in v1.9

  • OCTO connectivity. Horus now exposes the open standard API used by Civitatis, Viator, GetYourGuide and Klook. Platforms read your availability and sell directly.
  • Availability engine. One tour at a time, but several customers can join the same departure until seats run out.
  • Admin → Conexión OCTO. Supplier identity, sale cutoff, cancellation cutoff, hold duration, and one API key per reseller.
  • Catalogue → per tour. Toggle "Venta automática", seats per departure, departure times.
  • Anti-double-booking hardened. Platform holds now block the slot — previously only confirmed bookings did.
  • Platform bookings are protected. They can no longer be refused or deleted from Horus.
⚠ Important — the model changes. A tour with "Venta automática" enabled is sold by the platform without your approval. You no longer accept or reject those bookings; you are notified once the sale is done. Only tours you explicitly enable are affected — everything else keeps working exactly as before.
